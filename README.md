# Tutin — Your Digital Tuition Identity 🎓🚀

> India's leading digital tuition identity platform for independent tutors, coaching centers, students, and parents.

![Tutin App Preview](assets/images/tutin_logo_text.png)

## ✨ Overview

**Tutin** empowers private educators to manage batches, track tuition fees transparently, distribute study materials securely, and build their local reputation with verified student reviews and shareable digital profile cards.

This repository contains the complete responsive modern landing page for Tutin, designed to mirror the design aesthetics, color palette, typography, and features of the Tutin Flutter application.

---

## 🌟 Core Features

- **📱 Interactive Flutter App Replica Mockup**: Switchable preview between Teacher View and Student View with live notification interactions.
- **👥 Dual Persona Architecture**: Tailored value propositions for both **Tutors & Coaching Centers** and **Students & Parents**.
- **📍 Hyperlocal Tutor Search & Discovery Widget**: Filter verified educators by City, Board (CBSE, ICSE, State Boards), Class (1–12), and Subject.
- **💰 Interactive Fee & ROI Calculator**: Calculate monthly tuition revenues, recovered unpaid dues, and hours saved from automated accounting.
- **🗂️ Interactive Feature Showcase**: Deep dive into Smart Batches, Transparent Fee Cycles, Digital Teacher Visiting Cards, and Batch Study Materials.
- **⭐ Verified Testimonials Grid**: Genuine student, parent, and educator testimonials with category filtering.
- **❓ FAQ Accordion**: Instant answers to common onboarding and fee questions.
- **📲 Responsive Modals**: QR code app download modal and teacher onboarding registration form.

---

## 🎨 Tech Stack & Design System

- **HTML5**: Semantic, accessible, and SEO-optimized structure.
- **Vanilla CSS3**: Design tokens matching Flutter theme colors:
  - **Primary**: Deep Indigo (`#3730A3` / `#6366F1`)
  - **Secondary**: Teal (`#0D9488` / `#2DD4BF`)
  - **Status**: Paid Green (`#059669`), Pending Amber (`#D97706`)
- **Typography**:
  - Headings: **Poppins** (Bold, SemiBold, Medium)
  - Body: **Inter** (Variable)
- **Vanilla JavaScript**: Zero dependencies, ultra-fast performance.

## 🚀 Getting Started

Simply open `index.html` in your favorite web browser or spin up a local development server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node (npx)
npx serve .
```

Then visit `http://localhost:3000` in your browser.
